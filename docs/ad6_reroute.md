# AD6単独再配線の結果

2026-09-28。ユーザー指示「他の線は変更せず、この線だけ再配線」に基づく。正式PCBへ短縮案を反映。シルク整理・製造出力には進んでいない。

|項目|再配線前|再配線後|
|---|---:|---:|
|GPIO10 / J1-16 → R7-1|35.66 mm|26.12 mm|
|R7-2 → J3-12|47.57 mm|47.57 mm（変更なし）|
|AD6主経路合計|83.23 mm|73.69 mm|
|AD6ビア数|2|3|

9.54 mm（11.47%）短縮できたため、旧経路には改善余地があった。新経路はIn2.Cuから追加の貫通ビアでB.Cuへ移動し、下側への迂回を短縮する。R7側の既存F.Cu引出し・ビア、カートリッジ側全経路は維持。追加ビアは径0.60 mm／穴0.30 mm、変更区間の線幅は0.25 mm。任意角度の直線を含む。設計ルールの緩和はしていない。

短い経路とビア1個追加の交換条件であり、波形品質の改善を保証するものではない。可能な全経路の探索・最短性の証明はしていない。長さはトラック中心線の主経路で、ビア垂直長・パッド内部・抵抗内部を含めない。

## 他配線の保持と検証

- /MCU_AD6以外の全トラック・ビア624要素をKiCadファイルのブロック単位で比較し、完全一致。/CART_AD6も含む。
- 部品位置・回転、パッドネット、部品フィールド、シルク、図形は承認済み配置と一致。
- GNDゾーンは再充填。追加ビアに伴う局所的な銅箔除外が変化するが、In1.Cuは連続1領域を維持（8936.57 mm²）。
- 正式PCBの再充填・保存・回路図等価性を含むDRC: 違反0、未配線0、等価性問題0。
- ピンマップ/BOM/ERC、配置、製造ルール、配線、経路長計算・元ファイルハッシュ、C++17定義の検査が合格。

## 比較画像と再現資料

[変更前後PNG](../output/pcb/ad6_reroute/comparison.png)。左が再配線前、右が再配線後。実PCB座標、同一縮尺の上面視。赤=F.Cu、橙=In2.Cu、青=B.Cu、白丸=ビア。灰色は他の配線。

hardware/verification/ad6_reroute/に変更前PCB、変更前集計、探索用障害物、採用座標manual_path.json、結果result.jsonを保存。router.logは既存配線を保護したFreerouting試行がMCU側を完結できなかった記録で、採用結果ではない。続いて0.15 mm格子の層別探索と経路簡略化で短縮案を生成し、KiCad DRCで実際の形状に対して検証した。

再現時は同ディレクトリのbefore.kicad_pcbとmanual_path.jsonをtmp/ad6-reroute/へコピーし、KiCad同梱Pythonでtools/apply_ad6_path.pyを実行する（候補PCBのみ生成）。正式採用時にはプロジェクトルール下でDRC・再充填が必要。tools/export_ad6_obstacles.pyとtools/search_ad6_path.pyは探索補助（後者はNumPyが必要）。画像生成はtools/render_ad6_reroute.pyとNode sharp。画像は線幅を視認用に強調している。

旧FNK比較画像output/pcb/ad6_comparison/は、AD6再配線前の83.23 mm時点の履歴として維持。現行のFNK比較は[配線長比較](routing_comparison.md)を参照。
