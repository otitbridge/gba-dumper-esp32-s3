# WeAct ESP32S3-A N16R2 設計仕様

2026-09-28。正本識別子 `WEACT_ESP32S3_A_N16R2_GBA_V1_20260928`。元のGBAバス・ROM/SAVE・UART要求を継承し、ボード固有条件は本書とpinmap.mdを優先する。初期引継ぎ原文はarchive/fnk0099/docs/handoff.mdの履歴に保存。

- ESP32-S3-WROOM-1-N16R2（16 MB Flash、2 MB Quad SPI PSRAM）搭載のWeAct ESP32S3-A専用。GPIO35/36/37を使用可能な型番であることを到着時に確認。R8やB版へ転用しない。
- 子基板は無改造。GPIO2にLED負荷なし。RGB用48、Native USB用19/20、BOOT0、KEY45、ストラップ46、UART43/44はGBAバスに使わない。
- GPIO3=/CS2は100 Ω直列＋カートリッジ側10 kΩでHIGH保持。JP2装着で共通給電し、起動・リセット・UART書込み確認が必要。GPIO39〜42は通常GPIOへ設定。
- AD16本、AH8本、制御4本。ADはbank0内、AHはbank0/1跨ぎ。方向切替の排他制御、制御線HIGHを先にラッチして出力有効化、異常終了時の非選択復帰を維持。64ビットGPIOマスクを使用。
- R1〜24=330 Ω、R25〜28=100 Ω、R29〜32=10 kΩプルアップ、R33=10 kΩ PHIプルダウン。/REQはTPのみ。/WRはR27→JP1→カートリッジ、R31はJP1よりカートリッジ側。
- BOARD_3V3はJ1-1/2、GNDはJ1-22とJ2-1/21/22を接続。JP2→CART_3V3。C1=100 nF、C2=10 µF。5 Vは親基板NC。3.3 Vの供給能力は未検証。
- JP1初期OPEN、JP2通常CLOSE。EEPROM要求・Flash識別/バンク選択にはJP1装着が必要。読出し用プロトコル書込みとSAVE内容変更の許可を分離する。
- PCはUART側USB-C→CH343→UART0 TX43/RX44。115200 bpsで立上げ、921600は検証後。Native USBはV1では使用しない。GBAバスとは非接続なのでバス保護用の封止部材はBOMから除外。二つのUSB端子を同時給電しない。
- ESP-IDF+C/C++、内部RAM約4 KiBバッファ、PSRAMはV1では初期化しない。無線・RGB LEDドライバは起動しない。PSRAM無効化はGPIO解放のためではない。
- ROMはワードアドレス=byte_offset/2、16ビットをリトルエンディアンで保存。1ワードごとにアドレス再提示、初期待ち各1 µs・読出し待ち2 µsを評価出発点にする。容量は明示指定、ヘッダと境界検査、独立2回SHA-256照合。
- SAVEはSRAM/FRAM・Flash・EEPROM別ドライバ。未知種別への試し書き禁止。変更許可・バックアップ・型番/サイズ照合後のみ書戻し、全量ベリファイ。特殊カートリッジは対象外または個別検証。
- 通信のCRC・連番・オフセット・ACK/再送・タイムアウト・ABORT・書込み冪等性はprotocol.mdの要求を維持。ドライバ、確定通信仕様、無負荷試験FWは本段階では未実装。
- 100×100 mm FR-4 4層。In1.Cuを連続GND面として使う計画。配線工程でトラック・ビア・In1 GND面を作成済み。シルクの最終整理は次工程。Gate1〜3完了前は発注不可。
