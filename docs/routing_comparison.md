# FNK0099版とWeAct版の配線長比較

2026-09-28。同じ集計スクリプトで配線済みPCBを比較。FNK0099はmainの6403600時点を保存したarchive/fnk0099/gba_dumper.kicad_pcb、WeActは今回のhardware/gba_dumper.kicad_pcb。元ファイルのSHA-256はJSONに記録。

**総延長は約3.8%減、最長のGPIO〜カートリッジ経路はほぼ同じ。個別信号には増減があるため、全信号が同等とは扱わない。ユーザー指示によりAD6のみを追加短縮した。シルク整理には進んでいない。**

AD6は当初65.33→83.23 mm（+17.90 mm、+27.39%）だったが、[単独再配線](ad6_reroute.md)により73.69 mm（FNK比+8.35 mm、+12.79%）へ短縮。現在も増加率・増加量ともAD6が最大。最大減少はAD13:113.20→86.69 mm（−26.50 mm、−23.41%）。部品位置は承認済みWeAct配置を維持しており、これらはピン配置・禁止域・ルーター経路の違いを含む今回の結果である。ボード変更だけによる必然的増減や、最短配線の限界を示すものではない。

## 測定方法と限界

- 総延長・ネット合計はKiCadの全トラック中心線長の総和。TPやプルアップへの枝線を含む。GND面は長さに換算せず、面積・連結領域数を別集計。
- 主経路はGPIOソケット→抵抗pin1と、抵抗pin2→J3の中心線グラフ最短経路を合算。/WRはR27→JP1とJP1→J3も含む。T分岐を分割し、同ネットの導電パッドと貫通ビアで層間を接続する。
- 抵抗内部、ジャンパシャント、パッド内部、ビアの垂直バレル長、子基板上のESP32からヘッダまでの配線は含めない。親基板上の経路比較であり、電気的遅延・実装全体の配線長ではない。
- 経路を「合計ネット長」と混同しない。枝線を除いた主経路と、枝線を含む合計をCSVで併記。アークは今回存在せず、将来アーク追加時はスクリプトが拒否する。
- 等長配線、高速動作、波形品質を保証しない。立上げは従来の低速タイミングで行う。個別の増加が許容できるかは波形・実機読出しで確認する。
