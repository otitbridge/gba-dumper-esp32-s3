## 寸法・定格確認

- ヘッダ: 2.54mmピッチ、0.64mm角ピン、定格3A、接触抵抗20mΩ以下。推奨完成穴径1.02mm。ハウジング約5.08×2.5mm、高さ約2.5mm、基板側リード3.0±0.25mm。
- ヘッダの差込み側長さは商品欄6.1mm、[メーカー図面](https://akizukidenshi.com/goodsaffix/PH-1xXXSG_20260114.pdf)6.00±0.25mm。図面の寸法公差範囲で扱い、6.1mmを独立した厳密値としない。
- キャップ: 2.54mmピッチ、外形約5.0×2.44×13.5mm。メーカーの[2228XGシリーズ図面](https://akizukidenshi.com/goodsaffix/2228XG-XX.pdf)に定格3A AC/DC、接触抵抗30mΩ以下、2228GGつまみ付き形状を確認。
- 図面上の規格・構造から組合せを選定。実物での嵌合・着脱・導通確認は組立受入時に実施する。3A定格はWeActの3.3V出力が3A供給できるという意味ではない。

## フットプリントと接続

`GBA_Mechanical:PinHeader_1x02_P2.54mm_D1.02mm`をJP1/JP2へ割当。KiCad 10.0.5標準`Connector_PinHeader_2.54mm:PinHeader_1x02_P2.54mm_Vertical`を元に、穴径のみ1.00→1.02mmへ変更。パッドは1.70mm、pad1は矩形、中心は(0,0)/(0,2.54)。元形状の出典はKiCad同梱ライブラリ（kicad-footprints、CC-BY-SA-4.0 with KiCad libraries exception）。3Dモデルは標準ヘッダの参考表示で、キャップの高さは含まれない。

## 配置・運用

キャップ底面がヘッダハウジング上に近接すると、親基板面から約16mmの高さになる。これは概算。高さ公差・完全嵌合位置と着脱空間は配置レビューで確認し、WeAct下、カートリッジ下、USBプラグの通路には置かない。つまみを指で掴め、JP2の2ピンへ絶縁付き測定リードを接続できる空間を確保する。

JP1はWR ENABLE、JP2はPOWER LINK - REMOVE USB FIRSTと表示。操作は必ずUSB電源を抜いてから行う。JP2で電流測定する際も、無給電でキャップを外し電流計を直列接続してから給電し、再び無給電にして復旧する。JP1の状態をソフトで検出できるとはしない。
