# SAVEプロトコル — 未確定・未実装

SRAM/FRAM 32KiB、Flash64/128KiB、EEPROM512B/8KiBを独立ドライバで検証する。EEPROMはAD0専用シリアルでありI²CやSRAMルーチンを使わない。

allow_protocol_writesは既知の読出し要求/識別/バンク選択だけ。allow_save_mutationは既定false、種別確認・バックアップとハッシュ保存・明示許可後のみ。未知Flash IDへ消去や試し書きをしない。JP1 OPENでは全SAVE形式を読めない。

メーカー別コマンド、EEPROMビット列、アドレス長、タイムアウト、復帰シーケンスは部品仕様と参照実装を確認後に確定する。既存実装のコピーは未実施。使用時にはライセンスとコミットを記録。書込み後は全量読出し比較し、送信完了を成功判定にしない。
