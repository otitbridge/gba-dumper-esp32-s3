# WeAct N16R2のソケットと機械条件

公式ESP32S3-A外形図と回路図はhardware/reference/weactへ原本保存。各列22極・ピッチ2.54 mm・列中心間27.94 mm、端子列長53.34 mm。上面視でアンテナ上・USB下、左J1/右J2、上から1〜22の独自番号。モジュール端子番号と区別する。

J1/J2は `GBA_Mechanical:PinSocket_1x22_P2.54mm_D1.02mm`。穴径1.02 mm、パッド1.70 mm、1番矩形。2.54 mmピッチの22極形状を生成し、公式の列間隔で配置。旧20極の電気接続を流用しない。

採用品はRonmee FH2.54-40U1GF8.5-0.5（秋月110073）。40極品を2本購入し、各1本から22極を切り出す。計44極実装、余り各18極。メーカー/販売ページのピッチ2.54 mm、ハウジング高さ8.5 mm、推奨実装穴1.02 mmを2026-09-28再確認。細ピン用なのでWeAct付属ヘッダとの嵌合は未確認。FNK0099での嵌合確認をWeActへ転記しない。

[販売ページ](https://akizukidenshi.com/catalog/g/g110073/)

公式図の本体外形62.756×31.242 mm、アンテナ側の突出6.040 mm、モジュール幅18.017 mm。USB側の突出を除く長さ68.796 mm。端子中心と基板端のオフセットのうち幅方向1.651 mmは図示値。長手方向の1番端子〜アンテナ側基板端約4.865 mmは図の形状からの読み取り値であり、公差付きの寸法指示ではない。Dwgs.Userの外形配置はこの読み取り値を用いた配置レビュー用。到着時に照合する。

ユーザーから販売業者確認として、下面部品なし、USB位置・実装高さはFNK0099と同様との条件を受領。基板間隔最低2.5 mm・目標3.0 mm以上を組立検査の条件として維持する。下面のはんだ・端子突出にも接触しないこと。ハウジング高さをそのまま基板間隔と扱わない。

前のFNK0099配置に対するユーザー確認は新配置の実機検証とはしない。新しい配置はpcb_placement.mdと配置画像でレビューする。
