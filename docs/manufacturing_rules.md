# 製造ルール — JLCPCB / GBA DIRECT V1

更新日：2026-09-28。WeAct N16R2版。KiCad 10.0.5。現在の配置を維持し、配線開始用の設計ルールを設定した。製造承認・注文は行っていない。

## 製造前提

FR-4、100×100mm、4層、1.6mm厚、外層1oz・内層0.5oz、緑レジスト・白シルクを基準とする。表面処理はユーザー指定により**鉛含有HASL（通常のHASL）**とする。鉛フリーHASLではない。費用低減を目的とした2026-09-28の確定方針で、WeAct版の金額は未見積り。これらは注文に入力する設計前提であり、発注・見積り済みではない。特定スタックアップの誘電体厚・材質は注文時に照合する。インピーダンス制御は要求しない。

この指定は裸基板のランド表面仕上げに適用する。PCBAで用いるはんだペーストの組成を指定するものではない。旧FNK0099版の鉛フリーHASL見積り・HASL差額記録は履歴として残し、旧計算額4,453円を現行WeAct版の確定見積りとは扱わない。

エコノミーPCBAは上面のR1〜R33・C1/C2のみ（5品種35個）。J1/J2/J3/JP1/JP2は手はんだ、TPは露出パッド、H1〜H4は固定穴。Basic区分・在庫は発注時に再確認。

上記は本設計の採用値であり、製造業者の絶対限界値一覧ではない。電源線幅は給電能力の保証ではなく、電源回路の評価・実負荷測定は別途必要。J3形状と固定穴位置は維持し、J1/J2は22極・列間27.94 mmへ更新。

`Default` と `GBA_SIGNAL` は0.25mm配線、`POWER_3V3` は0.80mm配線。BOARD_3V3、CART_3V3、GNDを電源クラスへ、MCU_*、AD/AH・制御信号・PHI・WR_LINKを信号クラスへ割当。実ネット名のルートシート接頭辞 `/` を含めて全62接続ネットのクラス照合を実施。ネットクラスの線幅はルーター初期値であるため、電源最小幅0.50mmは `.kicad_dru` にも明記した。信号最小幅0.20mmは基板全体の制約。

ブラインド／埋込／マイクロビア、下面部品実装をカスタムルールで禁止。貫通ビアは両面テント設定を維持し、樹脂充填・銅蓋を前提にしない。In1.Cuは連続GND面として使う計画で、ゾーンと配線の実作成は次工程。アンテナ禁止領域は維持する。
