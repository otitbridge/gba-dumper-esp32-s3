# 製造ルール — JLCPCB / GBA DIRECT V1

設定日：2026-09-27。KiCad 10.0.5。現在の配置を維持し、配線開始用の設計ルールを設定した。製造承認・注文は行っていない。

## 製造前提

FR-4、100×100mm、4層、1.6mm厚、外層1oz・内層0.5oz、緑レジスト・白シルクを基準とする。表面処理は鉛フリーHASLを注文時の第一候補とする。これらは注文に入力する設計前提であり、発注・見積り済みではない。特定スタックアップの誘電体厚・材質は注文時に照合する。インピーダンス制御は要求しない。

エコノミーPCBAは上面のR1〜R33・C1/C2のみ（5品種35個）。J1/J2/J3/JP1/JP2は手はんだ、TPは露出パッド、H1〜H4は固定穴。Basic区分・在庫は発注時に再確認。

|信号線幅|標準0.25、最小0.20|
|電源・GNDの線幅|標準0.80、最小0.50（カスタムDRCで強制）|
|銅箔〜基板端|0.50|

|穴端〜穴端|0.45（ビアを含めて保守的に統一）|
|ビア|貫通のみ、標準外径0.60／穴0.30|
|最小ビア外径／最小穴径|0.60／0.30|
|最小ビア環状幅|0.15|
|PTHパッド最小環状幅|0.20（カスタムDRC）|
|NPTH最小径／長穴最小幅|0.50／1.00（カスタムDRC）|
|SMDパッド〜ビア穴|0.20以上（via-in-pad禁止）|

|シルク文字高さ／線幅|最小1.00／0.15|

|ゾーン初期値|離隔0.20、最小幅0.25、サーマルギャップ／スポーク幅各0.30|

上記は本設計の採用値であり、製造業者の絶対限界値一覧ではない。電源線幅は給電能力の保証ではなく、電源回路の評価・実負荷測定は別途必要。PTH寸法、J3形状、固定穴位置など承認済みの機械条件は変更していない。

`Default` と `GBA_SIGNAL` は0.25mm配線、`POWER_3V3` は0.80mm配線。BOARD_3V3、CART_3V3、GNDを電源クラスへ、MCU_*、AD/AH・制御信号・PHI・WR_LINKを信号クラスへ割当。実ネット名のルートシート接頭辞 `/` を含めて全62接続ネットのクラス照合を実施。ネットクラスの線幅はルーター初期値であるため、電源最小幅0.50mmは `.kicad_dru` にも明記した。信号最小幅0.20mmは基板全体の制約。

ブラインド／埋込／マイクロビア、下面部品実装をカスタムルールで禁止。貫通ビアは両面テント設定を維持し、樹脂充填・銅蓋を前提にしない。In1.Cuは連続GND面として使う計画で、ゾーンと配線の実作成は次工程。アンテナ禁止領域は維持する。

## 実装工程の追加準備

JLCPCBのエコノミーPCBAは位置決め用の丸い非メッキ穴（φ1.152mm、レジスト拡張0.148mm、2〜3か所）を要求する。H1〜H4のφ3.2mmは固定用であり代用とはしない。今回はルール設定の範囲で新しい穴を追加していない。注文時にJLCPCBによる追加を選択し、メーカーが追加したCAM上の穴位置を銅箔・部品・固定部と照合する方針。追加を任せられない注文条件の場合は、出図前に設計側で追加する。

搬送用捨て板・フィデューシャルの要否と追加方法も実装注文条件で確認する。これらを必要とする製造パネルの外形と、製品本体100mm角は区別する。追加加工位置・パネル・CPLの部品向きを確認するまではPCBA提出完了とはしない。

## 適用・検証

- `.kicad_pro`：基板最小制約、線幅・ビア候補、ネットクラス。
- `.kicad_dru`：貫通ビア限定、PTH/NPTH、via-in-pad、片面実装、電源最小幅。
- `.kicad_pcb`：レジスト最小ブリッジ0.10mm。
- `tools/configure_manufacturing.py`：KiCad同梱Pythonで再適用。既存配置・ネット・配線は維持する。
- `hardware/verification/manufacturing_drc.json`：今回のルールによるDRC結果。

結果：未配線86件、その他の電気・穴・クリアランス等のエラー0件。**既存シルク文字の高さ68件・線幅52件、合計120件の警告を検出**。高さ0.8〜0.85mm等の仮配置用文字が主因。警告を無視・除外にせず、製造用シルク整理で高さ1.0mm以上、線幅0.15mm以上に修正する。今回は部品配置確認済みのPCBを維持するため、文字の拡大や移動は行っていない。

以前の `placement_drc.json` は設定前の検査記録であり、現在の製造ルールに対する合格記録ではない。現ルールでの最終DRC合格、未配線解消、Gate1〜3完了はまだ必要。
