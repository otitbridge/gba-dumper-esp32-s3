# 引き継ぎ仕様の実装用要約

出典: ユーザーが2026-09-27に本タスクへ提示した「GBA専用ダンパー V1 — FNK0099 N16R8 / Codex・KiCad引き継ぎ仕様」全14章。**このファイルは原文の逐語保存ではなく要約。原文と食い違う場合は提示原文と最後の改造許容追記を優先する。**

- 識別子FNK0099_GBA_DIRECT_V1_20260927。GPIO割付はpinmap.mdおよびpinmap.hppへ転記。
- FNK0099 N16R8を1台使用。最後の追記により搭載表面実装部品の取り外し改造を許容。対象は未確定。
- GPIO35〜37はPSRAM無効化後も使用禁止。0/45/46も不使用、43/44はCH343 UART専用。
- GBA専用3.3V・32極、AD16+AH8+制御4本。GB/GBC/SFC、特殊機能、ROM書換えは対象外。
- R1〜24=330Ω、R25〜28=100Ω、R29〜32=10kΩでCART_3V3へ制御プルアップ。R33=10kΩでPHIをGNDへ。/REQはTPのみ。
- JP1はR27後段、初期OPEN。R31はJP1後段。JP2は3.3V電流測定・切離し用、通常CLOSE。C1=100nF/C2=10µF。
- Native USB端子を封止し使用禁止表示。GPIO19/20を通常GPIO化。RGB/LEDライブラリを起動しない。
- 電源投入前に装着。カートリッジ、ジャンパ、FNK0099の挿抜は全体無給電で行う。別電源並列・5V給電を禁止。
- まず無負荷→192Bヘッダ→ROMを2回取得・SHA-256比較→SAVE読出し→許可後の書戻し。
- バス所有者は単一タスク。制御ラッチHIGHを先に用意し、出力有効化。AD/AH待機時入力・内部プルなし。/CSと/CS2同時選択を禁止。
- ROMはバイトオフセット/2を24bitワードアドレスとして出力。読出しはlittle endian。1ワード毎に/CS解除し、方向切替前後に待機。
- 初期評価待機は設定/保持/切替/終了各1µs、/RD後2µs程度。保証値ではない。UART待ちを選択中にしない。
- ROM長1/2/4/8/16/32MiBは明示指定又は検証済情報。ヘッダだけでサイズ断定しない。未実装領域とEEPROM重複に注意。
- ESP-IDF+C/C++、16MB Flash、PSRAMなし、無線なし、内部RAM約4KiB、UART0 TX43/RX44 115200 8N1 フロー制御なし。921600は検証後の目標。
- SAVEはSRAM/FRAM 32KiB、Flash64/128KiB、EEPROM512B/8KiBを別ドライバで対応目標。未知SAVEへ試し書き禁止。
- allow_protocol_writesとallow_save_mutationを分離。後者は初期false、バックアップ・種別確認・利用者の明示許可が必要。書戻し後は全量比較。
- チャンク版/種別/連番/絶対offset/長さ/CRC、ACK再送、ABORT、範囲検査、書込み重複実行防止が必要。正式通信仕様は未確定。
- Gate1〜3完了前の発注禁止。機械寸法と実機試験は生成ソフトで代替しない。

現時点の成果は回路図とピンマップ。完成基板、動作FW、確定フットプリントは含まない。
