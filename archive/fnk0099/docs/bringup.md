# 検証手順とゲート

## Gate 1 — 論理（2026-09-27）

機械的検査: 32極・J1/J2・C++配列、28本重複なし、予約GPIO不使用、2/3/48をデータ入力にしない、GPIO3のプルアップ、JP1後段/WRプルアップ。検査はtests/hardware/check_design.py。ERCはhardware/verification/erc.rpt。実際の起動時HIGHの保証はGate2で確認する。

## Gate 2 — FNK0099単体（未実施）

1. カートリッジを接続しない。現物の型番・端子順・必要な改造を記録する。
2. Native USBを封止。CH343側から給電・UART書込みする。GPIO3に回路相当プルアップを設け、起動・リセット・復旧を確認。
3. 将来の無負荷試験FWで28本を安全な治具へ出力しHIGH/LOWを確認。GPIO19/20は入出力、39〜42は通常GPIO設定を確認。
4. GPIO2/48の負荷・波形、制御線HIGH電圧と起動時グリッチを測る。未知カートリッジとの競合試験をしない。

## Gate 3 — 機械・電源・PCB（未実施）

ソケット形状・実装高さ・下面部品はユーザー指定により既存WROVER設計の条件を採用（fnk0099_footprint.md）。スロット型番と導通、全体配置の干渉、電源余裕、封止を確認。確定フットプリントでPCBを設計してDRCを実施。3.3V-GND短絡・5V混入・抵抗バイパスがないことを確認。Gate1〜3を全て満たしてから発注判断。

## Gate 4 — 到着後ROM（未実施）

ソケット組立後、FNK0099下面と親基板表面の間隔が最低2.5mm（目標3.0mm以上）あること、下面部品が接触しないことを確認する。

JP1 OPEN、JP2 CLOSE。カートリッジなしで起動波形を測定。電源OFFで検証用カートリッジを挿入。供給電圧と/WR HIGH、AD方向切替順序を確認。192Bヘッダのタイトル/コード/固定値/チェックサム、先頭/境界/末尾を検査。明示サイズで2回独立に取得し長さ・SHA-256を比較。固定配線誤りは一致ハッシュのみでは排除できない。ABORT・切断・timeoutで非選択へ戻ることを確認。

## Gate 5 — SAVE（未実施）

既存SAVE退避、種別確定。EEPROM要求・Flash ID/バンク切替にはJP1装着が必要となるためUSBを抜いて操作。プロトコルコマンドと内容変更を分離。未知種別の書込み拒否、既知種別のタイムアウト、書戻し後全量比較を検証。対応表に構成・版・実測結果を記録。
