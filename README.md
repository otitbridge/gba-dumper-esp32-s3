# GBAダンパー — バイナリ配布

## 一緒に製品化してみませんか？

**スマホで完結するROMダンパーを目指しています。** GBAカートリッジのROMやセーブデータを、スマホのブラウザから操作して保存できる、手に取りやすい道具にしたいと考えています。**これから始める人の「入門用の1台目」**を狙っていきたいです。

動作する試作機とファームウェアができ、特定のカートリッジでROMの読み出しやセーブデータの読み書き・復元を確認しています。ここから、量産向けの基板や筐体、製造検査、販売・サポートまで、一緒に取り組んでくれる方を探しています。

私自身は利益を得ることよりも、試作から製品化までの経験を積むことを目的にしています。知識や得意分野を持ち寄り、相談しながら進められればと思っています。

評価用バイナリと検証結果・未検証事項を公開します。最新版の詳細設計とソースコードは、秘密保持契約（NDA）の締結後に、協業に必要な範囲で共有する予定です。既公開版と第三者素材のライセンス条件は引き続き維持します。

現在は初回のファームウェア書込み・機器Wi-Fiのパスワード取得にUART接続が必要です。その後のROM・セーブ操作はブラウザから行う構成です。実際のiPhoneでの動作確認はこれからで、初期設定も含めた使いやすさを一緒に整えていきたいです。

WeAct ESP32S3-A N16R2と本プロジェクトのGBA用基板V1（20260928）向けの開発版ファームウェアです。
現在の配布版は **0.11.1 / public build**。ソースコード・最新の設計ファイルは配布しません。GitHubは書込み用バイナリ、操作説明、不具合報告の窓口として使用します。

## 対応と確認範囲

- ブラウザからROMの独立2回読出し・全バイト照合・保存。
- 公式No-Introの登録情報からROM容量を設定。容量は物理測定による判定ではありません。
- EEPROMセーブの退避・書込み・元バックアップの復元。Web書込みは独自実機確認済みの設定だけを許可します。
- Wi-Fi接続設定・ESP32親機への自動切替・設定の保存。
- 開発用FWで「シナモン ふわふわ大作戦」4 MiB ROMとEEPROM 512 Bの読み書き・復元を実機確認済み。復元中断→再接続→元セーブ全量2回照合も確認済み。
- 配布用public buildはビルド・バイナリ検査済み。public buildそのものの実機書込み、初期NVSからの親機パスワード生成、実iPhone／Windows、書込み中のUSB抜去・スリープ、他カートリッジは未検証。
- 8 KiB EEPROMは模擬試験のみ。SRAM／FRAM／Flash、32 MiB ROMのEEPROMは未対応。ROM容量が登録済みでも、そのタイトルのセーブ書込みまで検証済みという意味ではありません。

## 書込み・初期設定・操作

[書込みと初回接続](INSTALL.md)、[操作と復元](USAGE.md)を参照してください。対応基板以外には書き込まないでください。

配布用ビルドには開発者のSSID・Wi-Fiパスワード・OTA認証局を含めません。親機のパスワードは機器内で生成してNVSへ保存します。既存の保存済みWi-Fi設定と親機パスワードは維持されます。
公開版のOTA開始は無効です。更新にはUART側USBを使います。Web UIのHTML／JavaScriptと容量一覧は機器からブラウザへ配信され、利用者が閲覧できます。
